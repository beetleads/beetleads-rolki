# Pula tematów na rolki (10-30.11.2026)

Każdy temat przeszedł trzy bramki: jest eksperyment z liczbą badanych,
jest jedna liczba do pokazania na ekranie, wynik jest wbrew intuicji.
Liczby potwierdzone w samym źródle (abstrakt albo PDF), nie w blogu.

Pliki po obszarach: `ceny.json`, `lokal.json`, `online.json`, `uslugi.json`.
Pole `uwaga` oznacza temat, którego NIE wolno publikować bez domknięcia
(np. brak linku do źródła).

Po wybraniu tematu do slotu dopisz go do `rejestr/tematy.json`
i przepuść całość przez `rejestr/sprawdz.py`.
